# Assistant Directory

Эта папка содержит спецификации, конфигурацию и служебные файлы ассистента, который управляет Obsidian-пространством через Telegram.

## Structure
- `SPEC.md` — продуктовая спецификация ассистента.
- `config/` — конфигурация расписаний, приоритетов и поведения.
- `logs/` — журналы действий ассистента и запросов пользователя.
- `prompts/` — системные и рабочие промпты.
- `schemas/` — формальные схемы сущностей и служебных форматов.
- `runtime/` — служебные файлы рантайма, если реализация решит хранить их в репозитории.
- `.workspace/` — здесь хранится пример пространства пользоавтеля, на который можно ориентироваться в начале проекта

## Intent
Этот каркас нужен как стабильная основа, поверх которой можно отдельно специфицировать и реализовывать сценарии через `speckit`.
