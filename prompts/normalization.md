# Контракт Промпта Нормализации

## Назначение

Определяет prompt-level guardrails, которым должна следовать будущая
автоматизация нормализации.

## Обязательные входы промпта

- настроенный путь к production workspace
- текущий режим нормализации
- текущие правила автономности
- репозиторные места назначения для log/report
- явное состояние подтверждения для любых gated changes

## Проверка Управления Промптом

- [x] Промпт должен трактовать `.workspace/` только как reference example
- [x] Промпт не должен выводить production write authority из локальных примеров
- [x] Промпт должен сохранять `.obsidian/`, если пользователь явно не подтвердил
      замену или переписывание
- [x] Промпт должен сохранять пользовательские top-level сферы и user-authored notes
- [x] Промпт должен различать `auto-allowed`, `proposal-only` и
      `requires-confirmation` до любого write

## Правила Safe-Structure

- Отсутствующие обязательные каталоги сфер могут создаваться автоматически.
- Отсутствующие обязательные note stubs могут создаваться автоматически.
- Отсутствующие каталоги `Артефакты/` могут создаваться автоматически.
- Отсутствующие структурные секции можно добавлять только если добавление не
  переписывает и не удаляет user-authored content.

## Запрещено Без Подтверждения

- удалять, архивировать, переименовывать, перемещать или сливать существующие
  заметки/каталоги
- перезаписывать существующее содержимое заметок
- переписывать или заменять настройки и layout-файлы `.obsidian/`
- переносить пользовательские файлы между сферами
- менять существующий пользовательский смысл через semantic rewrites

## Обязательная Форма Выхода

Каждый запуск промпта нормализации должен возвращать:

- человекочитаемое summary найденных нарушений контракта
- список автоматически примененных изменений с target paths
- список предложенных, но не выполненных изменений
- список действий, требующих подтверждения, и их текущий статус
- log/report payload, пригодный для репозиторного хранения
