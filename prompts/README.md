# Prompts

В этой папке должны храниться системные и рабочие промпты ассистента.

Предполагаемые группы промптов:
- `core` для главного оркестратора;
- `capture` для разбора входящих задач;
- `review` для утренних и вечерних ритуалов;
- `strategy` для стратегических сессий;
- `linking` для предложений по связям.

Промпты лучше хранить отдельно от кода, чтобы их можно было версионировать и дорабатывать независимо.
