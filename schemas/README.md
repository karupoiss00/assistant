# Schemas

В этой папке должны храниться формальные схемы данных ассистента.

Примеры будущих схем:
- формат входящей задачи;
- формат дневного плана;
- формат дневной рефлексии;
- формат weekly report;
- формат monthly review;
- формат action log.

Эта папка нужна как мост между продуктовой спецификацией и конкретной реализацией.
